A02 增加模型提供商 Schema 适配

请修复 A02，优先级 P1。责任范围：CMS。

审计证据：静态确认 真实请求待验。已观察的问题：完整前端 JSON Schema 直接传给 Vertex responseSchema，未区分提供商支持子集；真实线上失败率尚未验证。

首先检查：src/ai/content-engine.mjs；src/ai/vertex-gemini-client.mjs；src/ai/kimi-client.mjs；src/frontend-contract.mjs。

依赖：A01 A19。

实现要求：

1. 核对当前官方 Vertex 与 Kimi 文档，建立 provider-specific schema adapter。完整前端契约继续作为最终权威校验，不因模型限制删掉发布约束。

2. 对 oneOf/const/联合类型/可选字段等逐项处理并记录转换结果。必要时把选组件与组件数据生成拆分；不静默声称等价转换。保留 metadata 的合法输出结构。

3. 客户端解析 JSON 后做任务级 Schema 校验；将错误路径和约束反馈给有次数上限的修复请求。永久不兼容错误停止原样重试，输出可诊断代码。

4. 增加最小真实请求验证脚本，仅在凭据与授权可用时运行；保存脱敏请求结构、模型、日期和结果。无额度也必须完成 mock 与契约回归，不宣布真实调用通过。

验收要求：提供商请求符合其当前支持范围；不支持的约束有明确处理；畸形 JSON、Schema 不匹配、限流、截断均有预期结果；最终页面仍按原契约校验。
