# SoloToChina Content Production Strategy 1.9

状态：active；2026-09-10。应用 1.17.26；schema 55 不变。唯一版本清单为 `config/content-strategy.json`。继承 1.8 的证据、授权、时效共识、人工命题和商业隔离原则，变更以本规范为准。审计交付 requirementsVersion=1.3 独立于应用／策略版本。

## 生产单位与审批

生产单位是人工批准的、边界明确的文章提案，不是采集来源或潜力分。来源建议解释素材利用方式；一个来源可有多个方向，也可只进知识库。来源建议、创作方向、已批准方向分别计数，不能相加解释为可生产文章数。
保留授权单来源改编、窄专题和多来源综合；不新增需求发现、GSC 选题或外部问答挖掘。潜力分不构成自动批准。

- 默认文章和指定方向使用共同批准服务，确认面板显示具体标题；批准一个方向不批准其余方向。
- 批量最多 100 条明确选择的待处理记录，逐条检查版本、归属和证据，逐条事务提交并报告成功／跳过／失败，不覆盖已批准方向。
- 冻结目的地、标题、类型、生产方式、读者承诺、证据边界、实体范围及指纹。指纹不因就绪分变化而变化；提案变化须重新确认。人工命题写入相同格式的批准记录。
- 同目的地、类型、读者承诺和实体范围的精确规范化分组只供当前加载范围内比较；不是语义去重，不自动合并／删除。
- 规划提示词携带批准边界。保存规划前检查大纲非空、有事实引用、引用属于当前素材包且无严格冲突。该检查证明引用有效，不证明自然语言承诺完全得到证据支持；后续正文审核仍必需。
- 覆盖度是文章类型素材槽位的匹配分，不是事实正确率、文章完成度或发布许可；取消事实数量奖励。各生产方式仍分别执行证据准入。

## 阶段与质量

保留现有管线：人工批准 → 规划 → 草稿 → 素材／页面编排 → 审核 → 商业叠加与最终交付检查 → WordPress 草稿。
本版在既有审核阶段分离正文质量与图片／页面交付结论，没有新增每篇必跑模型调用，也没有将正文审核前移为第二次调用。
正文审核关注表达、事实支持、边界与可读性；缺图、缺渲染器、最终页面映射错误归交付问题，不扣正文子分或自动重写正文。总交付门禁仍要求所有必要检查通过。
审核绑定修订、内容及证据哈希。旧审核保留历史，不能作为新修订／新证据的当前结论；旧报告未拆分的子结论不追溯伪造。
SEO 技术、GEO 一致性、成本可观测性独立报告；技术通过不表示排名、索引、流量或 AI 引用提升。未配置真实价格时费用未知，不等于零。

## 菜单与恢复

来源负责采集、授权和溯源；建议负责来源利用决策与批量批准；创作规划（原选题）保留人工命题、素材体检与方向列表，不是每篇必经的第二次审批；内容负责当前任务、产物和恢复；异常链接同一恢复入口。
QA Queued 表示审核排队，不表示重写。未测试表示当前版本没有有效结论；注意表示有限制或未知信息；失败须看正文或交付的具体问题，不能一概理解为文章写坏。
恢复校验版本、活动任务、授权与阶段前置条件。入口提供原文链接、保留素材信息、已授权素材绑定、正文及证据台账修正、未规划的目的地修正和明确的单阶段执行。只重试失败阶段不自动串联后续付费阶段。
403 必须恢复合法可用原图或调整素材，不能绕过访问控制；400 输入／契约错误先修正输入。重新采集不是批准新文章，也不保证自动恢复旧失败草稿，应按入口重新检查并执行必要阶段。
比较修订比较历史版本；预览并取消是生产操作取消影响的预览，不是网页效果预览。

## 不变的安全边界、兼容和验收

不覆盖已批准范围、不删除旧策略机会、不追写旧产物版本、不因策略变化自动重分析所有旧来源；旧候选仍须人工批准。既有合法队列依既有授权运行，不利用重启制造新审批。
保留原始证据、历史、人工命题、Research／Commercial 隔离、WordPress 草稿保护及前端契约，不发明组件 ID、不修改另一仓库。
本版无数据库迁移；部署前生成数据库与原始／生成素材快照，恢复须配套原代码和数据。离线及隔离浏览器通过不替代真实付费模型、过期原图、生产 WordPress 或最终主题 HTML 验证。
实际验证和外部限制见 `docs/audit/EXECUTION_LOG.md`、`docs/audit/CONTENT_RECOVERY_2026-09-10.md`。1.9_DRAFT 保留设计过程，其早期断点不是当前功能声明。
