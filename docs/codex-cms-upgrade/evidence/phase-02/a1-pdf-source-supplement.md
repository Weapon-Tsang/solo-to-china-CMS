## Implemented scope

The Source image-context panel's file diagnosis now opens **为这份PDF补充图片**. Independent image bytes pass through the existing `CaptureMediaUploadManager` v2 receiver, chunk/status/complete protocol, original storage and verified receipt journal. A new append-only Source adapter saves a pending asset; the administrator confirms its page (optional), evidence caption and declared image role once. The panel refreshes after server confirmation, exposes the actual image preview and distinguishes source-supported relationships from unspecified candidates. It states **已加入来源素材，尚未替换文章配图**.

Each asset retains its own SHA-256, MIME, dimensions, original storage reference, durable receipt and idempotency key. Existing `provenance_json.supplement` records the parent PDF identity/hash, source/capture fingerprint, actor, times, optional page, confirmation hash and explicitly manual lineage. Unknown page/object/region stay null. No source/capture text, existing draft, frozen packet, article visual, publication mapping, job or budget is modified.

The parent is read from the server-selected storage root and parsed with the existing PDF parser to validate its real page count. Server checks reject stale source/PDF fingerprints, foreign assets, invalid pages, unverified receipts, arbitrary storage references and corrupt/mismatched bytes. Full image decoder traversal uses bounded concurrency and sharp's existing decompression protection; the diagnostic 32 MiB/40 MP budgets are not used as upload limits. The existing receiver's protocol capacity still applies. Failed originals/receipts are retained, not marked confirmed or deleted.

Manual classification is explicitly an administrator declaration (`manual-source-supplement-1`, provider `administrator`, `needs_review`), not model or independent pixel verification. JPEG/PNG does not automatically mean documentary photo. Captions pass through the existing typed relationship/conflict/revocation rules; titles do not name the new image. Appended images cannot inherit old numbered-figure references. Parent context changes invalidate manual relationships at read time. Existing article-specific required-media gates remain.
